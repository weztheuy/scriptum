Карта страниц:

/
├── /auth
│   ├── /login
│   └── /register
├── /works
│   ├── /new
│   ├── /:id
│   │   ├── /edit
│   │   ├── /download
│   │   ├── /comments
│   │   │   └── /:commentId
│   │   └── /chapters
│   │       ├── /new
│   │       └── /:chapterId
│   │           └── /comments
│   │               └── /:commentId
├── /authors
│   └── /:id
├── /account
└── /admin


Список маршрутов:

Аутентификация:
- /auth/login — вход
- /auth/register — регистрация

Произведения:
- /works — каталог произведений (поиск и фильтрация)
- /works/new — публикация новой работы
- /works/:id — страница произведения
- /works/:id/edit — редактирование произведения
- /works/:id/download — скачивание произведения

Комментарии к произведению:
- /works/:id/comments/:commentId — конкретный комментарий произведения

Главы:
- /works/:id/chapters/new — добавление новой главы
- /works/:id/chapters/:chapterId — страница главы

Комментарии к главам:
- /works/:id/chapters/:chapterId/comments/:commentId — конкретный комментарий главы

Авторы:
- /authors — список авторов (поиск и фильтрация)
- /authors/:id — страница автора

Пользователь:
- /account — настройки пользователя

Администрирование:
- /admin — некоторые административные функции

Запрещенные маршруты:
- /works/:id/chapters — вместо этого works/:id прогружает список всех глав
- /works/:id/comments — вместо этого works/:id прогружает список некоторого количества комментариев. Фильтрация и пагинация происходит инкапсулировано внутри api
- ../chapters/:chapterId/comments — вместо этого /chapters/:chapterId прогружает список некоторого количества комментариев. Фильтрация и пагинация происходит инкапсулировано внутри api
